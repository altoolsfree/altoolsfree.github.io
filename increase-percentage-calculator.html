How to increase a number by a percentage

To increase a number by a percentage, multiply the number by (1 + percentage / 100). For example, to increase 200 by 15%, multiply 200 by 1.15 to get 230.

  1. Turn the percentage into a decimal: 15% becomes 0.15.
  2. Add 1 to it: 1 + 0.15 = 1.15.
  3. Multiply the number by that value: 200 x 1.15 = 230.
New value = number x (1 + percentage / 100)

How to add a percent to a number

Adding a percent means finding that percent of the number and adding it on. To add 15% to 200, 15% of 200 is 30, so the answer is 200 + 30 = 230. The shortcut is the same as above: multiply by 1.15.

Decrease a number by a percentage

New value = number x (1 - percentage / 100)

Example: decrease 200 by 15%. 200 x (1 - 0.15) = 200 x 0.85 = 170.

How to calculate percentage increase between two numbers

% change = (new value - old value) / old value x 100

Example: from 50 to 65. (65 - 50) / 50 x 100 = 30% increase. A negative result means a decrease.

Percentage decrease

The same formula works for a drop. Going from 80 to 60 gives (60 - 80) / 80 x 100 = -25%, which is a 25% decrease.

Find the original number after a percentage increase

To go backwards, divide the new number by (1 + percentage / 100). If a number rose by 15% to 230, the original number was 230 / 1.15 = 200.

Where people use it

  • Salary raise: an 8% raise on 40,000 gives 43,200.
  • Price rise: a 12% price increase on a 250 item gives 280.
  • Adding tax or markup: adding 10% tax to a price of 80 gives 88.
  • Business growth: sales going from 12,000 to 15,000 is a 25% increase.
  • Rent and bills: add a percentage to a base amount.

Increase then decrease is not zero

Raise 100 by 50% and you get 150. Lower 150 by 50% and you get 75, not 100. The second percentage is taken from a bigger number. To go back to the start after a 50% increase, you need a decrease of about 33.3%.

Frequently asked questions

How do you increase a number by a percentage?

Multiply the number by (1 + percentage / 100). For example, to increase 200 by 15%, calculate 200 x 1.15 = 230.

How do I add a percent to a number?

Find the percent of the number, then add it to the number. To add 15% to 200, 15% of 200 is 30, so the answer is 200 + 30 = 230. A shortcut is to multiply by 1.15.

How do you calculate percentage increase between two numbers?

Subtract the old value from the new value, divide by the old value, then multiply by 100. For example, going from 50 to 65 is (65 - 50) / 50 x 100 = 30% increase.

What is the formula for percentage increase?

Percentage increase = (new value - old value) / old value x 100.

How do I calculate a percentage decrease?

Subtract the new value from the old value, divide by the old value, then multiply by 100. For example, going from 80 to 60 is (80 - 60) / 80 x 100 = 25% decrease.

How do I find the original number after a percentage increase?

Divide the new number by (1 + percentage / 100). For example, if a number rose by 15% to 230, the original was 230 / 1.15 = 200.

Why is a 50% increase followed by a 50% decrease not back to the start?

Because the second percentage is taken from a bigger number. 100 up 50% is 150, and 150 down 50% is 75, not 100.

Can percentage increase be more than 100%?

Yes. If a value more than doubles, the increase is over 100%. For example, going from 40 to 100 is a 150% increase.
