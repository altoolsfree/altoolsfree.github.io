What makes a password random?

In a random password, each character is chosen independently from the characters you allow. There are no words, no names and no keyboard patterns like "qwerty". That is why random passwords are very hard to guess, even for software that tries millions of combinations per second.

Random vs. made-up passwords

People are bad at being random. We tend to start with a capital letter, add a number at the end and use a familiar word. Attackers know these habits. A generated password skips all of them.

How this tool creates randomness

The generator uses the secure random number function built into your browser (crypto.getRandomValues). This is the same kind of randomness used for encryption. It is much stronger than the basic random function many simple tools use.

When to use a random password

  • Email, banking and shopping accounts
  • Wi-Fi router and device passwords
  • Any site where you do not need to type the password by hand often

Frequently asked questions

What is a random password?

A random password is made by picking each character by chance, so it has no pattern, word or personal detail that someone could guess.

Are these passwords really random?

Yes. The tool uses the secure random number generator built into your browser, not a simple Math.random function.

Can I remember a random password?

Random passwords are hard to memorize. Store them in a password manager and only remember one strong master password.
