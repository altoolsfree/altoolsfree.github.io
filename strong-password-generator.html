How strong is your password?

Password strength is measured in bits of entropy. Each extra bit doubles the number of guesses an attacker needs. With uppercase, lowercase, numbers and symbols all turned on, this tool gives roughly:

LengthApprox. strengthRating
8 charactersabout 51 bitsFair

20 charactersabout 129 bitsStrong

The three things a strong password needs

  • Length: aim for 16 characters or more for email, banking and your password manager.
  • Randomness: no names, dates or common words.
  • Uniqueness: never reuse a password. If one site leaks it, every account using it is at risk.

Add a second layer of protection

Even the strongest password can be stolen by a fake login page. Turn on two-factor authentication (2FA) wherever it is offered, and never type your password into a link you received by message or email.

Frequently asked questions

What is a strong password?

A strong password is long, random and unique. It uses at least 12 characters, mixes character types and is not reused on other accounts.

How is password strength measured?

Strength is measured in bits of entropy. More bits means more possible combinations. This tool shows an estimate based on the length and the character types you select.

Is a long password better than a complex one?

Length matters most. A random 20-character password is far stronger than a short one with many symbols.
