What Is a QR Code Generator?

A QR code generator is an online tool that converts text, website URLs and other information into a scannable QR code. QR codes can be scanned with a smartphone camera or QR scanning application.

How to Create a QR Code

Creating a QR code with ALTools is simple. Enter your text or website URL in the box above and click the Generate QR Code button. Your QR code will be generated instantly.

Create a QR Code for a Website URL

You can enter a complete website address such as https://example.com to create a QR code that can be scanned to open the website.

Create a QR Code for Text

You can also enter plain text and generate a QR code containing that information.

What You Can Put in a QR Code

  • Website link: https://example.com
  • Plain text: any short message or note
  • Phone number: tel:+1234567890
  • Email address: mailto:name@example.com

How to Save and Scan a QR Code

  • After the code appears, press and hold it on a phone (or right-click on a computer) and choose to save the image.
  • To scan a code, open your phone's camera and point it at the QR code.
  • Tap the link or text that appears on the screen.

Tips for a QR Code That Scans Well

  • Test the code with your own phone before you print or share it.
  • Keep it large enough. Printing it at about 2 cm × 2 cm or bigger works well.
  • Use dark code on a light background for strong contrast.
  • Shorter text or links make a simpler code that is easier to scan.
  • Do not enter passwords or private information. The code image is drawn by a third-party QR service.

Why Use a QR Code?

QR codes provide a convenient way to share website links and text. They are commonly used on websites, posters, flyers, menus, business cards, product information and promotional materials.

Frequently Asked Questions

Is this QR code generator free?

Yes. The ALTools QR Code Generator is free to use online.

Can I create a QR code for a website?

Yes. Enter your website URL in the input box and click Generate QR Code.

Can I create a QR code from text?

Yes. You can enter text and generate a QR code containing that information.

Do I need to install software?

No. The QR Code Generator works directly in your web browser. No software installation is required.

How do I scan a QR code?

Open your phone's camera and point it at the QR code. A link or text appears on the screen, so tap it to open. If nothing appears, try a QR scanner app.

Can I make a QR code for a phone number or email address?

Yes. Type tel: followed by the number, for example tel:+1234567890, or mailto: followed by the email address, then click Generate QR Code. Phones will offer to call or write an email when the code is scanned.

How do I save the QR code image?

After the QR code appears, press and hold it on a phone, or right-click it on a computer, and choose to save or download the image.

Does a QR code expire?

No. The text or link is stored directly in the QR code pattern, so the code itself does not expire. If the website it points to goes offline, the link will stop working.
