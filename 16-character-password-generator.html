What is a 16 character password?

A 16 character password is a password that is exactly 16 characters long. It can contain uppercase letters, lowercase letters, numbers and symbols. Because every extra character makes the password much harder to guess, 16 characters is a strong choice for email, banking and social media accounts.

How to create a 16 character password

  1. Choose the character types you want: uppercase, lowercase, numbers and symbols.
  2. Click Generate 16 character password.
  3. Click Copy and paste the password into the sign-up or change password form.
  4. Save it in a password manager so you do not have to remember it.

Why 16 characters?

Sixteen characters is a popular sweet spot. It is long enough to be very hard to crack, and short enough that most websites accept it. With all four character types, a random 16 character password has about 100 bits of strength.

16 character password requirements

  • Uppercase (A-Z): adds 26 more possible characters per position.
  • Lowercase (a-z): adds another 26.
  • Numbers (0-9): adds 10.
  • Symbols (!@#$): adds more, but a few websites do not accept them.

You do not need all four types. A random 16 character password with only letters and numbers is still very strong.

If a website rejects your password

  • Turn off Symbols. Some sites only allow letters and numbers.
  • Turn on Avoid look-alikes if you need to type the password by hand.
  • Check the maximum length. A few older sites limit passwords to 12 or 15 characters.

How to keep a 16 character password safe

  • Use a different password for every account.
  • Store passwords in a password manager instead of trying to remember them.
  • Turn on two-factor authentication (2FA) for email, banking and social media.
  • Never share a password by message or email.
  • Change a password right away if you think it was leaked.

Frequently asked questions

Is a 16 character password strong enough?

Yes. A random 16 character password with letters, numbers and symbols has about 100 bits of strength, which is far beyond what current attacks can crack.

How do I make a 16 character password?

Click Generate on this page and choose which character types to include. Every password is exactly 16 characters. You can also build one yourself by mixing uppercase letters, lowercase letters, numbers and symbols in a random order, but a generator is faster and more random.

What is an example of a 16 character password?

An example is PtYgj&mUh#Bel31i. It has 16 characters with uppercase and lowercase letters, numbers and symbols. Do not use this example for a real account, generate your own instead.

Does a 16 character password need symbols?

No. Length matters most. A random 16 character password made only of letters and numbers is still very strong. Add symbols if the website allows them.

What does a 6-16 character alphanumeric password mean?

It means the password must be between 6 and 16 characters long and use only letters and numbers, with no symbols. To create one here, turn off Symbols and generate a password. Use 16 characters for the strongest option the site allows.

Why do some websites reject 16 character passwords?

Some sites limit length or block certain symbols. If a site rejects your password, turn off symbols or use a shorter length.

Should I use 16 characters or more?

16 is a good minimum for important accounts. For a password manager master password, use a longer one.

Can I use the same 16 character password on many accounts?

No. Use a different password for every account. If one site is hacked, a reused password lets attackers try it on your other accounts.

Is it safe to use an online password generator?

This generator runs in your browser and does not save your password. Even so, store the password in a password manager and never share it by message or email.
